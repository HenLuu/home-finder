# 第一次使用家庭找物

未选范围时，引导用户从一个常用抽屉、收纳盒或柜层试用。用户想一次拍整个房间或更大区域时，按该范围给拍摄指引，先从入口拍地标，再按实际走拍顺序展示各柜。可以用旧片段、新视频或照片。第一批录入后将本次范围内所有已确认的物品或分组导出到同一张可搜索 HTML，请用户在网页换种说法查一次。

## 用视频录入

1. 先拍能认出位置的柜体外观，再在同一段里打开柜门或抽屉。
2. 在内部稳住两三秒，把相邻的格子或层位带进画面。重点物品可以再靠近一点，拍清颜色、纹样、吊坠、包装或标签。
3. 想说就简单说「这是卧室衣柜中层的收纳盒，里面有围巾」。系统从清楚的画面补充可见信息。相似物品叠在一起时，只有想区分它们才需要拨开或补近照。只拍到收纳盒时先记录可确认的位置；物品本身看不清就标待补。

## 用照片补录

有条件时拍一张认位置的外观图，再拍一张能看清物品的图。单张近照也可用。只拍到物品而没有柜体或已知位置时，补一句它在哪，或先把位置留作待补。输入本机文件路径或附上能读取的照片。

## 试着查找和更新

- 给第一段素材时，可以说「录入这段视频，位置是客厅电视柜左侧的抽屉」。
- 录入后打开本地 HTML，先搜一个物品名、颜色或柜名，再点结果跟实拍找。用户在聊天说「书房里那个蓝色收纳盒放哪了」时，核对并给出可点开的物品路线。
- 原处查过了，说「原处没找到，我最后一次看到它时在……」，进入失物回溯。
- 实际移动后，说「我把蓝色收纳盒移到书柜上层了」，并明确物品与新位置。

已有家庭档案时从现有档案继续。首次建档前让用户选择一个本地文件夹。若用户要求初始化，可在确认的文件夹中新建 `家庭物品档案.json`，内容先用空档案结构：

```json
{
  "schema_version": 1,
  "sources": {},
  "locations": {},
  "items": []
}
```

CLI 没有自动创建档案的命令；如用户希望自行建档，也可手动保存这段 JSON。保存后先运行 `check`，再开始录入。照片等附件由用户保存在同一文件夹内的相对路径下。只问怎么用或怎么拍时，先给引导和可直接照说的一句示例；不要替用户选择保存位置或在用户要求初始化前创建档案。网页可用已确认的名称、别名和可索引特征检索。需要理解含糊描述时从聊天协助确认，再将有依据的更新导出到页面。
