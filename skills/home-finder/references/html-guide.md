# HTML 导览

## 一页可搜，命中后逐步找

每个已录区域的本地 HTML 从其家庭档案导出。首页可搜名称、别名、可识别类别、颜色和收纳位置，选择结果后进入稳定物品 ID 的实拍路线。照片必须来自该条目的当前位置参照或物品证据。只有口述位置时，页面按已知步骤指路并标口述；旧物品照留在历史。原有标记经同一位置和证据验证后可继续复用。

- 将导览页保存在用户选择的本地档案文件夹，并沿用用户现有的文件名；首次导出时使用清楚、稳定的文件名。单页可搜索，也可按房间、柜体和收纳点浏览。实际录入或移动后刷新总览页，并刷新受影响的区域页。
- 查到物品后，给出本地文件的 `#物品ID` 入口。若客户端打开本地链接时丢失片段，同时给搜索首页和可输入的关键词。要链接某个柜子或颜色结果，使用 `#search=编码后的关键词`。链接应指到实际可读的文件。
- 网页搜索只用档案明确的词和当前导出模板支持的类别与颜色。对于「做早餐时用的那个」「标签好像有几条线」之类的抽象描述，在聊天核对用途和证据。有两个候选时让用户确认；确认的新别名可补给同一条目，确认的新物品则按录入流程建档。只有用户已确认或授权的改动进入正式档案。

## 导出及刷新

先用档案脚本 `check` 核对当前版本。再用本 Skill 的 `scripts/export_guide.py`，传入 `--catalog` 档案、`--template` 本 Skill 的 `assets/guide.template.html` 和 `--out` 输出页；输出路径应位于用户选择的本地档案文件夹。导出指定区域时用 `--room '房间名'`，全部区域不传 `--room`。首次替换旧版或刷新时，只有用户选择复用已有同格式导览时才传 `--previous`；导出器会先验证当前档案和照片，再验证旧导览中的路线与证据，只有匹配的路线和标记会继续保留。导出器可读取正在替换的同一个 HTML。原有页面不是这种格式时，先做独立候选和人工核对，保留原页面。新档案的首次录入按提交范围导出，后续新增或移位后重新导出受影响的区域，覆盖物品从旧区域移出或进入新区域的情况。

已知找物先检查页面与当前档案是否一致；需要刷新时先导出候选并核对。正式采用前保留旧文件的本地备份，核对结果可搜、物品链接可进入、路径及照片来自最新记录。演练在副本中做。导出失败时说明具体原因，恢复可验证的导出后再交付当前路线。HTML 为独立快照，离线运行，档案提交后的重新导出由 Skill 工作流执行。
