# 失物回溯

为同一次找物在对话中保留物品身份、最后确认、用户说过的动作、待查点和已查范围。允许用户记不清、修改回忆或暂停。重开聊天时，只恢复实际可见的状态，缺了就请用户简述最后确认和已查处。演练或假设只产生演练结果。

## 建立起点

- 有多个同名物品时，先用颜色、用途或主人区分；问题里已经能区分时直接继续。已知档案可提供旧位置与日期，用户刚确认的所见优先。用户说「应该」「可能」的线索按其不确定程度记录。
- 第一轮优先问最后一次**确定**看到、拿着或用到它时正在做什么。之后只补最能缩小范围的一问，例如接着去了哪里，或哪一刻换包、换衣、需要空手。先让用户自由回忆，再给提示。线索已经够用就直接提出查法。
- 最后确定在家外，或不确定有没有带回家时，先用这条线索确认家内外的边界。家里的收纳档案可以提供原处，不能证明物品带回了家。

用户说的名字可能是近音，且已有相关素材时，优先用能定位的旁白和少量帧核对名称、手指示和标签。能确认的录像位置注明录制时间，供这次优先核查。当前是否还在原处，等用户实际查看。名字或罐子仍不明确时，先用实拍外观或原包装请用户辨认。

## 提出和更新待查点

每次最多给三个有线索的地点。优先最后确认附近可落下的位置，其次是确认经过的腾手、转移或中断节点。每个点说明「为什么先查」「怎么查」及所依赖的条件。仅知道房间时止于房间内可描述的范围。候选不足时少给或先问一个关键问题，避免用常见收纳点补满。可附已有实拍作为地点参照，不把照片当成本次物品在场的证据。

用户回报时更新该次检查范围：

- **查过了**：按用户实际检查过的范围记下。完整翻过的地方从当前建议移除，除非新线索支持重查并说明具体原因。
- **只看了一眼**：保留没查的具体部分，例如包底或内袋，下一步只补这一部分。
- **找到了**：结束当前搜索，区分「这次在哪里找到」与「以后固定放哪里」。只有用户明确要登记或实际移动时，才按既有录入、移位规则记录。发现位置、猜测和问答过程不会自动改写固定位置。

输出以接下来能做的动作开头。需要复盘时列「最后确认 / 待查 / 已查」，把旧档案、这次的口述事实和推测分开。有新线索就只改受影响的排序，不重复询问用户已答过的事。
